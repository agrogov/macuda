## What is implemented

| op | forward | backward |
|---|---|---|
| `k_silu_mul_fwd/bwd` | `act = silu(h1) * h2` (D§4.5) | `dh1 = dact*h2*dsilu(h1)`, `dh2 = dact*silu(h1)` |
| `k_sigmoid_gate_fwd/bwd` | `out = o * sigmoid(gate)` (D§4.7 last lines) | `d_o = dout*s`, `dgate = dout*o*s*(1-s)` |
| `k_gdn_gates_fwd/bwd` | `beta = sigmoid(bb)`, `g = -exp(A_log)*softplus(aa+dt_bias)` (D§3.6 / D§4.8 last lines) | `dbb = dbeta*beta*(1-beta)`, `daa = dg*(-exp(A_log))*dsoftplus(aa+dt_bias)` |

* softplus is torch's: `u > 20 ? u : log1pf(expf(u))`, and its derivative is `u > 20 ? 1 : sigmoid(u)` (the linear
  branch's derivative, which is what autograd returns). `sigmoid` is `1/(1+expf(-u))`, so a very negative `u` gives
  exactly 0 rather than a NaN.
* The reference exports the five scalars too (`ref_sigmoid`, `ref_silu`, `ref_dsilu`, `ref_softplus`, `ref_dsoftplus`),
  so ref/conv.c (the silu after the causal conv) and later refs can share one definition instead of writing a fourth
  copy.
* All three ops are elementwise grid-stride, one thread per element, 256 threads a block, grid capped at 65535 (the
  design §8.1 pattern). Nothing reduces and nothing is atomic, so the card's value is fp32 arithmetic in the same order
  as `ref/act.c`; only the libm functions differ (≈1 ulp, seen as ≤3e-7 below, against gates of 1e-5/1e-4).
* gdn_gates indexes its two `[heads]` tables with `i % heads` (entry `i` is token `i/heads`, head `i%heads`).

## Two interface decisions (please keep them when M4/M5 call these)

1. **`heads` is a parameter of `gdn_gates_fwd/bwd`.** The plan's signature listing omits it, but beta/g live per
   (token, head) and `A_log`/`dt_bias` are `[heads]`, and the design's rule is "dims as parameters so gradcheck can
   shrink them" (D§8.1/M3.1 style). Passing it also let the tests use `heads = 3` (uneven division) as well as the
   model's 16. Order: `(bb, aa, A_log, dt_bias, beta, g, n, heads, stream)`.
2. **Every wrapper takes a `cudaStream_t` last, 0 = default stream**, like the existing `jt_fill` in `kernels/misc.h`.
   The plan's signature shorthands (`silu_mul_fwd(h1, h2, act)`) drop it; the header is the source of truth.
* `k_sigmoid_gate_bwd`'s output pointer is named `d_o` (`do` is a C++ keyword, so the header could not be included from
  `.cu`, `.c` and `test/*.c` otherwise).
