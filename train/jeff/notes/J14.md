## Decisions a later task must know (each is checked, not assumed)

* **The GDN conv is patched as well as the rule.** Design §10.2 says to replace `torch_chunk_gated_delta_rule`; on gpubox
  `causal_conv1d` is installed and the hub-kernel decorator on `causal_conv1d_fn` routes it to a **CUDA-only custom op**,
  so a CPU dump dies with `Expected x.is_cuda() to be true`. `dump_ref.py` therefore also replaces
  `modeling_qwen3_5.causal_conv1d_fn` with `literal_conv` (design §3.6's taps: `tap 0` multiplies `x[t-(K-1)]`,
  `tap K-1` multiplies `x[t]`, then bias, then silu) and asserts 18 calls of it too. This is a design-text gap worth
  fixing in `docs/training/jeff-trainer-design.md` §10.2 by whoever owns the doc (not my file).
* **`logits` is `[2,5]`, not `[2,255]`.** Design §10.2 writes `logits [2,255]`; train.py's `option_logits` slices to
  `[:, :live.shape[1]]`, i.e. the widest row's live option count (5 here: the fixture's `--opts` are the default random
  2..6, giving rows of 3 and 5 options). train.py wins (D§1.1), so jefftrain must dump the same narrow width; a
  mismatch is a `shape` FAIL in `compare_layers.py`, which is strict about shapes on purpose.
* **The dead readout rows have exactly zero gradient.** Because of that slice, `grad.readout` rows 5..254 are exactly
  0 (checked: `max|.| 0`). jefftrain must mask the same way, or `grad.readout` will differ at rel 1.
* **`compare_layers.py`'s defaults are the plan's gates** (`--atol-rel 1e-3`, `--grad-rel 5e-3`), and `grad.*` keys use
  the second. `in.ids`/`in.off` must match exactly. Missing keys, shape changes, NaNs and an empty intersection are all
  failures; nothing is ever loosened. The reference is the *second* file's role in the formula's denominator: `rel =
  max|a-b| / max|b|`, i.e. b is the reference — call it as `ref.safetensors out.safetensors`.
* **Padding carries no gradient** (`padded-grad max|.| 0` in the dump, printed): the batch is right-padded and causal, so
  the packed layout `layer.{i}.in/out/post_mixer` and every `grad.*` are exactly the rows' real tokens.
* `in.ids` is the fixture's ids, **packed** (not padded to 70); jefftrain only needs the real tokens, and `in.off`
  gives the row boundaries. `pad_id` (248044, the tokenizer's eos) appears only inside the model's forward.
